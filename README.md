## ⚡ About

This repository contains the practical programs for a **Data Structures & Algorithms Lab**, implemented in C and organized by topic. The structure is designed for quick revision, easier compilation, and clean academic submission.

The repository focuses on the fundamentals: recursion, arrays, pointers, searching, sorting, memory addressing, stacks, and queues.
